# DoubleYou


**DoubleYou** is a microblogging platform that allows users to share short messages, interact with others, and experience a lightweight, fast social feed.

Built with modern web technologies, DoubleYou focuses on simplicity, speed, and a clean user experience.

---

## 🚀 Tech Stack

* **Frontend:** Nuxt 3
* **Backend / Database:** Supabase
* **Authentication:** Supabase Auth
* **Styling:** SCSS

---

## ✨ Features

* 📝 Create and publish short posts (microblogs)
* 🖼️ Attach images to posts
* 📰 Real-time feed of user posts
* 👤 User authentication (sign up / log in)
* ❤️ Interactions: likes and comments
* ⚡ Fast and responsive UI powered by Nuxt 3
* ☁️ Backend powered by Supabase (database + auth)

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/TheFunnyDay/DoubleYou.git
cd DoubleYou
```

Install dependencies:

```bash
npm install
```

---

## ⚙️ Environment Setup

Create a `.env` file in the root directory and add your Supabase credentials:

```env
SUPABASE_URL=your_supabase_url
SUPABASE_KEY=your_supabase_anon_key
```

---

## 🧪 Run the Project

Start the development server:

```bash
npm run dev
```

The app will be available at:

```
http://localhost:3000
```

---

## 🏗️ Build for Production

```bash
npm run build
npm run preview
```
